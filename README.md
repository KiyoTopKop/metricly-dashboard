# Metricly Analytics Dashboard

Metricly is a responsive, accessible SaaS analytics dashboard for monitoring fictional customer activity and subscription performance.

## Live preview

**[Open the Metricly dashboard](https://metricly-dashboard.kiotopkop.chatgpt.site)**

## Features

- Dataset-derived total users, active users, MRR, and engagement metrics
- Case-insensitive search by customer name or email
- Combined subscription-plan and account-status filters
- Sorting by name or engagement
- Responsive customer cards with long-content support
- Accessible account-details dialog with keyboard focus handling
- Users-by-plan visualization with equivalent readable values
- Visible focus indicators and reduced-motion support

## Run locally

Download or clone this repository, then open `index.html` in a modern browser. No dependencies, server, or build process are required.

## Technology

Semantic HTML, embedded CSS, and vanilla JavaScript. All customer information is fictional demo data.
